# Kaleidoscope

An interactive kaleidoscope drawing application built with Python and Pygame. It allows users to generate symmetrical art patterns by drawing freehand curves, adjusting parameters, and managing layers.

## Features

-   **Freehand Input**: Supports drawing arbitrary curves on the canvas with a mouse to serve as the base pattern.
-   **Parameter Adjustment**:
    -   **Slice Count**: Input a numeric value to change the number of symmetrical axes in the pattern.
    -   **Symmetry Mode**: Provides two modes: "Kaleidoscope" (rotation + mirror) and "Rotation Only".
-   **Brush System**:
    -   **Brush Types**: Includes Line, Circle, and Spray brush types.
    -   **Gradient Color**: Set a start and end color for a smooth color transition along the stroke.
    -   **Brush Size**: Adjust brush thickness easily with a slider.
-   **Layer Management**:
    -   Each generation operation creates a new, separate layer.
    -   A layer panel is provided to view, select, and delete specific layers.
-   **Dynamic Effects**:
    -   An option to make the final artwork auto-rotate.
    -   An option to make the final artwork pulse with a rhythmic scaling effect.
-   **Export Functionality**:
    -   Export the static canvas as a **PNG** image.
    -   Record the animated canvas with dynamic effects and export it as a **GIF** animation.

## Installation and Usage

### 1. Prerequisites
- Python 3.8 or higher.

### 2. Installation
Clone this repository to your local machine:
```bash
git clone https://gitee.com/flowingr/kaleidoscope.git
```

Navigate into the project directory and install the required dependencies:
```bash
cd Kaleidoscope-master
pip install -r requirements.txt
```
*(If the `pip` command points to a different environment, it is recommended to use `python -m pip install -r requirements.txt`.)*

### 3. Running the Application
```bash
python main.py
```

## How to Use
The application interface is divided into three sections:
- **Left - Drawing Area**: Click and drag with the left mouse button to draw a curve.
- **Middle - Control Panel**: Used to adjust all drawing parameters and trigger actions.
- **Right - Layer Panel**: Used to manage the generated drawing layers.
